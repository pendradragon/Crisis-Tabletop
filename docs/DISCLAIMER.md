# Disclaimer
**This is a __training__ tool, not a real emergency response tool**

Everything this application generates -- situation updates, consequences, severity assessments -- is fiction and generated by an AI model for the purpose of tabletop training exercises. 
Things this application is not: 
	- Real-world emergency guidance
	- A subsitute for your organization's actual emergency operations plan, business continuity or incident response plan
	- Reviewed or validated by certified emergency management, security, or legal professionals

This is used as *practice* decision-making and communication under pressure, not as a source of truth for how a real incident would unfold. 

## Data Handling
While you fill out your "organization profile" field, that text is sent **directly** to Anthropic's Claude API to generate the exercise. Please read the following before inserting **anything** to this application:
	- **Do NOT enter real organization information**
		Includes no real employee names, account numbers, credentials, network diagrams, security control diagrams, or anything you don't want seen and processed by a third-party AI service. 
	- **Fictionalize your organization.** Describe a similar generic organization. You'll still get useful information without the specifics. 
	- **Sessions are held in memory only** by default in this implementation (see `engine/sessionStore.js`). They are not written to a log file or database by this application. If you deloy this application somewhere else, modify it, you (the editor) is responsible for how the data is stored, handled, and used. See `SECURITY.md` for more details. 
	- If you are running this for  an actual organization's own preparedness program, loop in the person responsible for the organization's data handling/security before uploading **anything other than generic information**. 

By downloading and/or using this tool, you acknowledge that you have read and fully understand the information above.
